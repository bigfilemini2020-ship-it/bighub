# BigHub 작업 인계 - 2026-08-07

## 현재 결정

- 로그인, 사용자/승인, 게시글/댓글/완료: Supabase.
- PDF, 이미지, HTML 등 일반 첨부: Google Drive.
- 영상: Google Drive나 Vercel을 경유하지 않는다. Mux Direct Upload 후 Mux 스트리밍.
- Vercel은 현재 중단 상태이므로 배포, 파일 전송, 앱 업데이트 경로로 사용하지 않는다.
- 데스크톱 앱 업데이트는 테스트 중에는 수동 설치, 실제 배포 시 GitHub Releases 기반으로 전환한다.
- 앱 버전 및 설치 파일은 기능 수정이 모두 끝난 뒤 사용자 확인을 받고 한 번만 올린다.

## 현재 작업 상태

- Mux용 Supabase Edge Function 초안 생성됨.
  - `supabase/functions/mux-create-upload/index.ts`
  - `supabase/functions/mux-upload-status/index.ts`
  - `supabase/functions/mux-playback-token/index.ts`
  - `supabase/functions/_shared/mux.ts`
- 아직 앱 화면 및 업로드 흐름에 연결하지 않았다.
- 따라서 현재 설치본의 영상 업로드는 Mux를 사용하지 않는다.
- `mux-video-upload.test.js`는 기대 동작을 적어 둔 테스트 초안이다. 구현 전이므로 통과를 주장하면 안 된다.

## 다음 작업 순서

1. Mux 대시보드에서 토큰 종류와 요금제 한도를 확인한다.
   - 필요한 값: Mux Token ID, Mux Token Secret, Signing Key ID, Signing Private Key.
   - 값은 채팅, 앱 코드, Git에 넣지 않는다. Supabase Edge Function secrets에만 저장한다.
2. 기존 Drive 업로드 기능을 바꾸지 않고 파일 분기만 추가한다.
   - `video/*`, `.mp4`, `.mov`, `.webm` 등: Mux Direct Upload.
   - 나머지: 기존 Google Drive 업로드.
3. 파일 선택 누적 버그를 먼저 재현 테스트로 고친다.
   - 파일 A 선택 -> 파일 B 선택 -> A+B가 남아야 한다.
   - A+B 동시 드래그도 동일해야 한다.
   - 각 항목별 삭제가 가능해야 한다.
4. Mux 업로드 성공 후 피드에서 인코딩 대기 상태를 표시한다.
5. Mux asset이 `ready`가 되면 signed playback token을 받아 Mux Player로 재생한다.
6. 위 흐름을 로컬/데스크톱에서 실제 PDF 2개와 영상 1개로 검증한다.
7. 그 뒤에만 설치 파일을 생성한다. 버전 변경은 사용자에게 묻고 한 번만 한다.

## 반복 금지

- Google OAuth Playground, Drive OAuth client, refresh token 설정을 다시 시도하지 않는다.
  - 기존 Drive 업로드에서 실패했던 경로이며, 영상 해결책이 아니다.
- Vercel에 영상/이미지/첨부파일을 올리거나 프록시하지 않는다.
- Vercel 자동 업데이트를 다시 구성하지 않는다.
- 실패 원인과 재현 확인 없이 설치 파일을 새로 만들지 않는다.
- 동작 확인 전 "수정됨", "완료"라고 말하지 않는다.

## 현재 알려진 문제

- 연속 파일 선택 시 앞 파일이 사라지는 문제.
- Drive 직접 업로드가 간헐적으로 `Failed to fetch`, 사용자 정보/권한 오류를 보임.
- Drive 이미지가 간헐적으로 깨짐.
- 현재 설치본의 파일 업로드 실패는 Mux 미연동 상태와 별개로 Drive 경로 문제다.
- 이미지/첨부를 Drive에서 열 때는 Drive 응답과 공유 권한에 따라 동작한다. Vercel 대역폭을 사용하지 않는다.

## 운영 한계

- Mux 비용/용량/재생 한도는 계약 요금제에 따라 다르므로 대시보드 확인 전 안전하다고 단정하지 않는다.
- 영상은 Mux로 전송/스트리밍하므로 Vercel 사용량과 분리된다.
- PDF/이미지/첨부 다운로드는 Google Drive가 직접 제공한다. 앱은 파일 ID/링크만 보관한다.
